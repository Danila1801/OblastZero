# OblastZero

An early-stage Unity 6 project. Scaffolding only, no gameplay code yet.

## Status

**Not started.** This repository currently contains a Unity 6 (6000.4.6f1)
Universal Render Pipeline project skeleton: render pipeline assets for PC and
mobile, an input actions map, and the default sample scene. None of the game
itself is written yet.

It is public as a placeholder for future work. If you are here from my profile,
the projects worth looking at are
[Kaolin](https://github.com/Danila1801/Kaolin),
[Nook](https://github.com/Danila1801/Nook), and
[Portativ SRL](https://github.com/Danila1801/PortativSRL).

## Tech stack

- **Unity 6** (6000.4.6f1)
- **Universal Render Pipeline**, configured for both PC and mobile
- **Unity Input System**

## Run it locally

Open the folder in Unity Hub with Unity 6000.4.6f1 or newer, then open
`Assets/Scenes/SampleScene.unity`.
